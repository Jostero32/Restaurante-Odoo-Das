Payment Kushki

Integration of payment provider Kushki (kajita), in Odoo e-commerce store.

Installation

To install this module, you need to:

  • Update module list.
  • Install module.

Configuration

To configure this module, you need to:

  • Register in kushki platform and configure kajita: (https://uat-console.kushkipagos.com/auth/signup).
  • Configure kushki payment provider (Public Merchantmd, Private Merchantmd and Kformid).
  • Configure kushki payment method.

Usage

To use this module, you need to:

  • By activating the payment provider Kushki will now be available in our store to make online payments with credit cards.
